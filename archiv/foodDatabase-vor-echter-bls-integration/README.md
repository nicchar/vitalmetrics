# Archiv: foodDatabase.json (724-Eintrag-Version)

Diese Datei war die ursprünglich aus dem Monolithen (VitalMetrics.html) portierte,
handkuratierte Liste von 724 Lebensmitteln mit 19 Nährwerten je Eintrag. Sie wurde
mit "BLS 4.0" beschriftet, war aber keine echte Integration der offiziellen
Datenbank – nur eine manuell erstellte Auswahl gängiger Lebensmittel.

Ersetzt am 20.07.2026 durch die echte, vollständige BLS-4.0-Datenbank
(Max Rubner-Institut, 7.140 Lebensmittel, 19 der 138 verfügbaren Nährstoffe
übernommen), lizenziert unter CC BY 4.0. Quelle: https://blsdb.de

Aufbewahrt zur Nachvollziehbarkeit / falls ein Rollback nötig wird.
